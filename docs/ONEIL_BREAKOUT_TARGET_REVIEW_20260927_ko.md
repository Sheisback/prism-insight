# 오닐식 상단 매물 없는 돌파 목표(2a) · 보고서 전문 근거 가드 검토 기록

## 1. 변경 유형·범위

- **경제적 의사결정 변경**(목표가 산정 1개 분기 추가)과 **가드 문구 보강**(새 규칙 없음)입니다.
- 바꾸는 계층은 BUY 판단(프롬프트 + 같은 계층의 출력 계약 검증) 하나입니다. 스크리닝, 결정론적
  buy gate의 임계값, SELL, 사이징, 주문 경로는 바꾸지 않습니다.

## 2. 가설·유효 국면·반증 조건

- **문제(운영 증거):** #747(9/17) 이후 구조적 목표가 "보고서 1-1의 가장 가까운 주요 저항까지 거리의 80%"로
  고정되었습니다. 52주 고점 부근 종목은 가장 가까운 저항이 돌파 대상 고점 자체이므로 목표 여력이
  구조적으로 몇 %에 그칩니다. 로컬 운영 DB 사본(9/19 스냅샷)에서:
  - 9/16~17: 목표 여력 +7%~+79%, R/R 1.6~18.7
  - 9/18 KR: 000660 +2.1%(R/R 0.4, F1–F4·모멘텀 2개·MA50 위 통과 후 "손익비 기준으로 미진입"),
    001440 +0.8%(R/R 0.3), 006340 +0.06%(R/R 0.0)
  - 9/18 US: MRNA +1.0%, ARE +0.5%, SMCI +0.7% (R/R 0.1~0.2)
- **가설:** 오닐의 매수 자리(신고가 돌파, 위 매물 없음)에서는 목표를 규칙으로 정하는 것이 원 전략과 맞습니다.
  #747이 없앤 "+15~30% 임의 대체값"은 근거 없는 추정이었지만, 오닐 자신의 규칙("20~25% 익절, 7~8% 손절")과
  거의 겹칩니다. 그래서 **조건을 충족할 때만** 고정 비율 1.20(오닐 규칙의 하단)을 명시된 규칙 출처로 인정합니다.
- **유효 국면:** 모든 국면에 적용하지만, 약세 국면의 기존 보수 장치(min_score 5~6, 모멘텀 2개, 추가 확인 1개,
  분포일 kill switch)는 그대로 둡니다.
- **반증 조건:** 2a로 진입한 거래의 20거래일 성과가 같은 기간 일반 structural 진입보다 기대값이 낮거나,
  (c) 추격 한도 안에서도 진입 후 5거래일 안에 손절되는 비율이 기존 진입보다 뚜렷이 높으면 가설이 틀린 것입니다.

## 3. 기존 전략과의 궁합(실제 경로 추적)

| 단계 | 코드 위치 | 이번 변경의 영향 |
|---|---|---|
| 스크리닝 | `trigger_batch.py`, `prism-us/us_trigger_batch.py` | 없음. 모멘텀 트리거(갭·일중 상승·마감 강도·거래량)는 신고가 종목을 걸러내지 않습니다. 52주 고점 필터는 역발상 가치 트리거(고점 대비 -15~-40%)에만 있습니다. **수정 불필요.** |
| BUY 판단 | `cores/agents/trading_agents.py`, `prism-us/cores/agents/trading_agents.py` | 목표 산정에 2a 분기를 추가합니다. (a)는 기존 모멘텀 신호 3(52주 고가 95%)과 같은 기준이고, (d)는 기존 T1/T2 게이트입니다. 점수·매트릭스·손절 규칙은 그대로입니다. |
| 출력 계약 | `prism_core/trading_scenario_contract.py` | `source_type="oneil_breakout"`을 허용하고, ENTRY일 때 목표가가 분석 진입가 × 1.20(±1%)인지 코드로 검증합니다. 모델이 비율을 부풀려 R/R 하한을 넘기는 것을 막습니다. |
| 결정론 buy gate | `cores/buy_gate.py` | 변경 없음. 재계산 R/R 하한·손절폭·산술 일치 검사를 그대로 받습니다. 2a 목표는 R/R ≈ 20/손절폭 이므로 산술 검사와 모순되지 않습니다. |
| 사이징·주문 | tracking agent | 목표가에 의존하는 사이징이 없습니다. 목표가 없는 ENTRY에만 쓰는 `_dynamic_target_price` 보완 경로는 영향이 없습니다. |
| SELL·보유 | `cores/oneil_fallback.py` TIER3, AI 매도 에이전트 | 목표가는 강세 국면에서 자동 매도가 아닌 trailing 전환 마일스톤이고, 약세 국면에서도 종목이 강하면 보유합니다. 2a의 "규칙 기반 마일스톤"과 같은 의미입니다. |

- **중복 보상·제재:** 2a는 목표가만 정합니다. (a)가 모멘텀 신호 3과 겹치지만 점수를 더하지 않고, 목표 산정
  조건으로만 씁니다.
- **미확인:** 운영 서버의 9/19 이후 DB(특히 9/23 5장 도입 이후)는 이 Mac에서 접근하지 못했습니다.

### 보고서 전문 근거 가드(②)

- #765 이후 BUY는 5장·경쟁사 표를 포함한 보고서 전문을 읽습니다. 그런데 "새 미진입 사유·감점을 만들지 말라"는
  안전 문구는 인용 규칙 플래그(`PRISM_BUY_REPORT_DEPTH_EVIDENCE`, 꺼짐)에 묶여 있어 실제로는 빠져 있었습니다.
- 이번 변경은 인용 규칙(근거 매핑)은 켜지 않고, **가드 문구만** 기본 프롬프트의 EVIDENCE_RECONCILIATION에
  넣습니다. 일반적 공시 위험(차입·보증·우발채무·소송·희석)은 그 존재만으로 high severity나 "추가 확인 필요"
  사유가 되지 않습니다. 감사의견 비적정·계속기업 불확실성·거래정지·상장적격성 문제는 기존 단독 사유 4로
  다룰 수 있게 남겼습니다.
- 플래그 OFF 시 표 이름('경쟁사 비교 분석')이 기본 프롬프트에 나오지 않는다는 기존 불변식을 지켰습니다.
