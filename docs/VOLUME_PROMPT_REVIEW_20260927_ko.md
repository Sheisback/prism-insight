# KR/US 거래량 해석 프롬프트 보완

## 범위와 기준선

- 기준선: `9203306b` (별도 worktree `거래량-보는거-보정`).
- 사용자 승인: 2026-09-27, 양국 프롬프트 개선 및 검증 후 배포.
- 유형: 경제적 판단에 영향을 줄 수 있는 프롬프트 해석 보완 및 자료 완결성 지침 수정.
- 변경 대상: KR/US BUY·SELL의 한국어/영어 지침. 스크리닝, 점수/국면 매트릭스,
  손절/트레일링, 주문·수량, JSON 계약, fallback 및 별도 매도 루프는 보존한다.
- 1분봉 최대량의 20~30%, 신규 눌림목 트리거, 새 거래량 가점/하드게이트는 도입하지 않는다.

## 가설과 반증

상승 추세의 지지 유지·하락 폭 축소·거래량 감소는 정상 조정일 수 있다. 감소만으로
추세 반전/매도를 지시하던 문구를 제거하면 기존 복합 매도 원칙과 정합성이 높아진다.
반대로 지지 붕괴·손절 충족을 저거래량이라는 이유로 보류하거나 정상적인 고거래량
돌파를 고점이라는 이유로 차단한다면 보완 가설에 반한다. 성과 개선은 미입증이다.

## 실제 경로와 역할

- KR `trigger_batch.py`: 거래량 급증/횡보 발견은 전일 대비. US
  `prism-us/us_trigger_batch.py`도 전일 대비. 발견 이유를 20일 평균 비율로 읽지 않는다.
- 양국 `cores/agents/stock_price_agents.py`: 일봉 OHLCV→가격/거래량 보고서.
  US `cores/data_prefetch.py`에는 기술 팩트와 완결성 정보가 있다. 기존 데이터 수집은 유지한다.
- 양국 `cores/agents/trading_agents.py`: BUY의 20일 평균 2배/최근 3세션,
  돌파·트리거 가산은 보존하고 별도 거래량 가점은 추가하지 않는다. 입력에서 기준 기간,
  세션, 확정 여부를 확인하며 부족하면 미확정으로 남긴다.
- KR `stock_analysis_orchestrator.py`는 `EnhancedStockTrackingAgent`를 생성한다.
  `stock_tracking_enhanced_agent.py`의 SELL override가 실제 LLM 프롬프트를 사용한다.
  기본 `stock_tracking_agent.py`의 규칙 기반 매도를 정규 배치 전체로 일반화하지 않는다.
- US `us_stock_tracking_agent.py`는 SELL LLM을 사용하고 실패 시 O'Neil fallback을 사용한다.
- BUY 결과는 `cores/buy_gate.py` 및 주문 직전 가격·예산 심사를 거친다. 수량 계산은 기존
  계좌 예산 기반이며 거래량에 따른 비중 조정을 추가하지 않는다.
- SELL의 저거래량 하락 문구와 기존 복합 추세약화 우선순위의 충돌을 해소한다. 기존
  법인이벤트·손절·트레일링과 별도 hardstop/trend-exit 루프의 권한을 보존한다.
- KR SELL의 14:50 확정 가정은 BUY와 같은 출처 기반 확정 원칙으로 맞춘다.
  양국 SELL의 14일 조회 지침은 20일 기준을 실제 확인할 충분한 이력을 요청하도록 보완한다.

## 비교·검증 계획

1. 기존 프롬프트/매매 계약 테스트를 기준선에서 실행한다.
2. 실제 agent factory의 KR/US·ko/en 입력 지침을 검사하고 아래 양방향 사례를 지침에
   명시해 보존한다: 지지 유지 저거래량 조정, 거래량 동반 지지 붕괴, 정상 고거래량 돌파,
   저거래량 신고가/신저가만 있는 경우, 미완성봉·이력 부족, 손절 충족.
3. 주문 없는 기존 BUY 게이트·시나리오·예산·SELL 경계 테스트와 PR CI를 실행한다.
   문자열/팩토리 검증은 LLM의 실제 판단 또는 성과 비교가 아님을 구분한다.
4. 수정은 해석 계층 하나에 한정한다. 동일 후보 LLM 전후 비교·시간순 holdout·비용/체결을
   포함한 수익성 연구는 이번 배포의 성과 증거로 주장하지 않는다. 새 숫자 임계값 시도는 0개다.

## 유지·중단·복귀와 관측

기존 국면·위험 한도를 그대로 사용한다. 배포 직후 운영 Python의 factory smoke와 서비스,
cron 불변을 확인한다. 첫 정규 KR/US 배치는 별도로 관측 여부를 기록한다. 첫 배치부터
3개 정규 거래일 동안 판단 근거에 미완성봉 확정, 저거래량 단독 매도/매수, 손절 무시가
나타나는지 검토 대상으로 삼는다. 이는 수익성을 증명할 표본 수가 아니다.
문구 회귀/자료 오류/시장 국면/집행 오류를 구분하고, 새 문구가 안전 규칙을 덮는 사례가
확인되면 해당 프롬프트 변경을 revert PR로 복귀한다. 성과 저하만으로 자동 전략 전환하지 않는다.

## 현재 상태

사전 검토 및 좁은 프롬프트 보완 구현 완료. 실후보의 기존/신규 LLM 판단 비교와
전 경로 동일 후보 궁합 검증은 미실시이며 수익 개선·궁합 검증 완료를 주장하지 않는다.
배포 전 테스트, 정확한 PR head CI, 운영 스모크와 첫 정규 배치는 후속 증거로 구분한다.
