# 의미 기준 누적 직관 통합

## 목적과 경계

사용자 요청: 사실상 같은 원칙은 표현이 다르더라도 하나로 합친다.
기준선 `e1f03a02`의 활성 직관은 45개다. 현재 참고/개선 제안/미검토 구분,
시장·판단 단계, SHADOW 설정은 유지한다. 새 매매 규칙을 만들지 않는다.

## 확인한 원인과 변경 계획

- 원문의 숫자 집합이 모두 같아야 하는 조건 때문에, 공통 행동이 같아도
  일부 사례에만 세부 기준이 있으면 전체 묶음이 거절될 수 있었다.
- 단어·업종 표지의 일치 검사가 의미가 같은 바꿔 쓰기까지 차단했다.
- 하나의 거절 사유로 동의어 묶음 전체가 남는 경우를 줄이기 위해, 거절 근거에
  따른 재제안을 한 번만 허용한다. 끝없는 반복이나 목표 개수 맞추기는 하지 않는다.
- 제안과 별개의 검증 문맥에서 원문별 조건·행동·예외 보존을 확인한다.
  검증한 내용과 원본이 그대로인 경우에만 의미 기준 승인으로 적용한다.
- 숫자와 예외는 공통 문장에 억지로 일반화하지 않고, 해당 상황에 붙여 보존한다.
  같은 표현의 반복은 대표 원칙 하나로 줄인다. 반대 행동·새 조건·근거 없는 완화는 거절한다.

## 검증과 운영 적용

표현만 다른 원칙, 일부에만 있는 조건부 수치, 실제 반대 행동, 오래된 승인,
시장/적용 단계 차이, 반복 근거·원문 보존을 격리 DB에서 시험한다.
운영 기억 복사본으로 실제 모델의 전후 개수와 대표 문장을 확인한 뒤,
정확한 PR head CI와 clean ff-only 배포를 거친다.
운영 적용 전 원본과 검증 결과를 백업하며 거래·메시지 배치를 시험 삼아 실행하지 않는다.
새 통합 문장은 기존 적용 승인을 상속하지 않고 다시 검토한다.

첫 정규 배치와 수익성 효과는 별도 관측 사항이다.
