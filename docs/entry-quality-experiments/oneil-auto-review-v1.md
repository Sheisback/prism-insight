# 자동 베이스·성장 검토 v1 — 한정된 연구 가설

2026-09-27 사전등록. version=`oneil-auto-review-v1`. 분류기 가설1개이며,
성과를 보고 경계값이나 탐색 순서를 고르지 않는다. 기존 50/80/100 sizing은 바꾸지 않는다.

## 출처와 한계

- [IBD Flat Base 교육자료](https://shop.investors.com/images/promotional/flat-b-b_112408.pdf):
  최소5주, 깊이15% 이내, 선행 상승과 베이스 고점 위 매수점을 설명한다.
  그림의 선행 상승30%와 고점+0.10달러를 초기 연구 기준으로 사용한다.
- [IBD 20 Rules](https://shop.investors.com/images/promotional/20-Rules_102808.pdf):
  최근 분기 EPS·매출의 전년 동기 대비25% 이상 성장을 제시한다.

아래 자동화는 모든 CAN SLIM 요소나 모든 차트 패턴을 구현하지 않는다.
정확한 모양 대신 간단한 규칙을 쓰는 별도 재진입 v2와도 다르다. 기존 BUY·재진입을
막지 않으며, 이 분류기를 통과하지 못했다고 종목의 경쟁력이 없다고 해석하지 않는다.
베이스 종류·기간·선행 상승 측정창·상대수익 정의는 PRISM의 제한된 구현 가설이다.

## 입력 계약

- 하나의 symbol/decision/가격 기준, source_ref와 실제 available_at을 가진
  일봉 OHLCV, 시장 SPY 일봉, 분기 실제 재무 수치가 필요하다.
- 거래소 캘린더는 검토 주의 일요일까지 포함해 미완성 주를 완성 주로 오인하지 않게 한다.
  available_at와 평가시각 전에 실제 마감된 거래일만 사용한다. 미래 봉은 사용하지 않는다.
- 실제 수집 시각만 아는 현재 제공자 재무 snapshot은 현재 판단용으로만 사용할 수 있다.
  분기말 날짜를 발표일로 쓰지 않는다. 과거시점보다 늦게 받은 재무를 소급 적용하지 않는다.
- 분기 수치는 실제 diluted EPS와 total revenue의 동일 제공자/통화/범위여야 한다.
  추정치, 연간값, basic EPS 대체, 음수분모 비율, 발표/관측시각 미확인은 채우지 않는다.

## 고정 자동 분류 규칙

### Flat-base 부분집합

1. 마지막 완성 거래주를 끝점으로5~8개 완성 주를 짧은 순서대로 검사한다.
   이는 기간 후보4개를 포함한 고정 분류 절차이지 결과 수익률 최적화가 아니다.
2. 모든 예정된 거래일의 유효한 봉이 있어야 한다. 베이스 최고가는 첫 주에 있어야 한다.
   단순히 계속 상승한5주를 횡보 베이스로 잘못 분류하지 않기 위한 우리 제한이다.
3. `(최고가−최저가)/최고가 <= 15%`.
4. 베이스 직전60거래일의 최저가 대비 베이스 최고가 상승이30% 이상이며,
   베이스 고점이 그60일의 최고가 이상이어야 한다. 직전60일 마지막 종가도 첫 종가 이상이어야 한다.
5. pivot=베이스 최고가+0.10USD. 베이스 이후 최신 완성 일봉이 베이스 저점을
   깨뜨렸다면 해당 후보를 인정하지 않는다. 단계 수(몇 번째 base)는 판별하지 않는다.
6. 필수 봉/가격 조정 근거가 부족하면 MISSING. 다른 패턴은 이 규칙에서 미확인이다.
   분할이 있는 비교 구간은 가격 기준 재검증 전 MISSING이다. 알려진 배당은 가격 수익률
   기준임을 표시하며 총수익률로 부르지 않는다.

### Growth/outperformance 부분집합

1. 최근 보고 분기의 diluted EPS와 매출이 각각 전년 동기 대비25% 이상 증가.
   양의 전년 EPS·매출과 유한한 현재값이 필요하다. 실제 분기 데이터만 사용한다.
2. 동일 fiscal-period 비교는 최근 분기말과 약1년(365±7일) 전의 유일한 분기말로
   제한한다. 이는52/53주 회계연도 허용을 위한 구현 범위이며, 회사의 재무 범위가
   달라졌거나 비교 가능한 자료인지 확인할 수 없으면 MISSING이다.
3. 최근 분기말이 평가일보다180일 넘게 오래됐으면 MISSING이다.
4. 같은61개 거래일 종가로 계산한60구간 가격 수익률이 SPY보다 높아야 한다.
   이는 IBD RS 등급·동종업계 순위가 아니라 고정 벤치마크 대비 단순 초과수익이다.
5. 모든 조건이 충족되면 이 연구의 성장/상대강도 기준을 통과한 것으로 표시한다.
   연간3년 성장·ROE·기관보유·산업군 순위까지 검증한 기업이라고 부르지 않는다.

## 출력과 기존 연결

결정론적 계산서와 검토 JSON을 별도 보조 보고서로 생성한다. 기존 보고서의 문장을
수정하지 않는다. 계산 입력 hash, source refs, 가격/기간/성장률/상대수익과 reason을 보존한다.
`VALIDATED_RULE_OUTPUT`은 등록된 계산 규칙을 통과했다는 뜻이며 외부 데이터의 진위를
독립 감사했거나 사람이 승인했다는 뜻이 아니다. 기존 source-bound setup 어댑터로 연결한다.
베이스와 성장 기준이 모두 확인된 경우에만 setup을 제공한다. 결측과 조건 미충족을 구분한다.

## 도입 검토·검증

- 경제적 의미가 있는 연구 입력 분류기이며 운영 게이트가 아니다. 기존 broad screening,
  F1~F4, 보고서·BUY/SELL·재진입 v2 정의를 대체하지 않는다.
- `oneil_watchlist.py`의20일 최고가와 `regime_entry_policy` 통과를 새 증거로 전용하지 않는다.
- 기존 `prefetch_financial_statements`의 표는 재사용 가능한 현재 제공자 자료이나,
  행/기간/actual/available_at을 명시한 구조화 없이 문장으로 통과를 추정하지 않는다.
- 정상 flat base/얕은 급등/깊은 조정/선행 하락/5주 미만/미완성 주/휴일누락,
  동일 분기·추정치 혼합·음수 EPS분모·미래재무·벤치마크 날짜 불일치를 검사한다.
- 입력→자동 계산서/검토 JSON→setup→기존 적응형 sizing을 같은 후보로 시험한다.
- source와 버전이 고정된 후 전진 표본에서만 성과를 검증한다. 이 기능 테스트는
  수익성 근거가 아니다. 운영 연결/스케줄/LIVE 전환은 하지 않는다.
