# 기계적 추가 진입과 트레일링: 연구 계약 v1

2026-09-27, 작성자 Codex. 경제적 정책 연구이며 운영 연결/승격은 승인 범위가 아니다.
기존 batch-r-v1은 그대로 보존한다. family=micro-split-mechanical, 조건 조합 2개.

## 결과를 보기 전에 고정한 조건

US의 기존 신규 진입 E, 원본 초기 손절 S, R=E-S를 고정한다. 초기 10%,
E+0.5R/1R/2R에서 목표 30/60/100%. 각 단계 진입 상한은 해당 문턱+0.5R.
계획은 최초 진입부터 5일(달력일) 동안만 증액에 유효하며 종료는 원래 청산 시점이다.
정규 배치의 LLM 수정은 고정 원문이 없으므로 재생하지 않는다. 이 실험은 최초
고정 계획의 기계적 실행 가능성과 트레일링 효과만 분리한다.

비교 A: 최초100%, 원래 청산. B: 기계적 증액+초기 고정 손절.
C: B+트레일링. A의 원래 손절/매도 이력은 재구성하지 않는다. B−A에는 새 기계적
손절 효과도 포함되므로 증액만의 인과효과로 부르지 않는다. C−B가 트레일링 차이다.

5분봉을 사용해 정규장 개장 후 매10분에 평가한다. 신호는 방금 완료된 봉 종가,
가상 집행은 그 시점부터 시작하는 다음 봉 시가이며 신호 봉 시가로 집행하지 않는다.
실제 실행 지연을 재현하지 않는 이상적 시가 가정이다. 비용 편도10bp/25bp를 모두 보고한다.
10분 사이의 봉 저가에서 체결됐다고 가정하지 않는다. 10분 감시 사이 손절 이탈과 갭
손실이 발생할 수 있으며 트레일링 손절은 체결 가격을 보장하지 않는다.

한 평가 시점 한 단계, 단계 건너뛰기 없음. 실행 가격도 문턱/상한 및 평균매입가
초과 조건을 만족해야 한다. 현금 상한 U=1, 비용 포함, 소수 수량 전략 원장이다.
추가 후 stop 기준 예상 손실과 양방향 비용 합이 최초 100%의 R/E를 넘으면 증액 거절.
이는 종목별 위험 상한이며 포트폴리오·갭·정수주 위험 보장이 아니다.

C의 trailing: 완료된 10분 평가 종가의 최고가 H가 E+R 이상일 때
stop=max(기존stop,H−R). 현재 시세≤기존 또는 새 stop이면 청산 우선.
보호 청산은 증액 계획 만료 후에도 계속한다. stop은 하향 금지.
증액 후 체결 수량/평균가를 기준으로 재평가하되 가격 하락을 이유로 증액하지 않는다.

## 자료와 판정

기존 US Packet c5a78c224a47011e8d5a3d61은 이미 결과를 본 탐색 자료다.
정확한 entry/position 연결, R, 청산시각·가격, 정규장 가격 연속성, 기업행사 기준,
재생 입력 해시가 있어야 역사 비교가 가능하다. 없는 값을 역산하지 않는다.
시장시각·원본 시나리오 수정 이력·정수주·실계좌 체결은 별도 검증 범위다.

Primary: C−B의 순 슬롯 손익 평균. Secondary: A 대비 승자 이익 포착률,
초기 R 정규화 최대 불리 손익. 최소30종료/20진입날짜/10승자, primary+0.1%p 이상,
승자 포착90% 이상, 최고승자 제거 후 개선 방향 유지, 두 비용 모두 통과해야 한다.
holdout은 코드/입력 계약 검토 후 별도 freeze부터90일. 지금 시작된 것으로 보지 않는다.
자료 부족은 CONTINUE_CAPTURE, 가설 미충족은 RETIRE 검토. 자동 승격 없음.

## 시스템 궁합과 미완료 경계

기존 hardstop_seller는 다중 holding 행을 건너뛰므로 기존 피라미딩 행을 그대로
추가하는 연결은 안전하다고 볼 수 없다. tracking의 stop ratchet은 재사용 후보지만
정규/기계 배치가 공유할 campaign 단계·주문 intent·체결 복구·원자적 중복 방지는
실행 원장 연결 검증이 필요하다. 오프라인 재생은 이를 증명하지 않는다.
스크리닝→보고서→BUY→gate→주문→SELL 같은 후보 통합 검토도 미완료다.
실험 때문에 production caller, cron, LLM prompt, 기존 위험 한도를 바꾸지 않는다.
