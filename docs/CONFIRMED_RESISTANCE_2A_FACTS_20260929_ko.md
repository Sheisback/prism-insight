# 당일 장중 고가 저항 배제 + 52주 고가(2a) 팩트 (KR/US)

## 1. 변경 유형·범위·기준선

- 유형: **정확성 수정 + 기존 규칙 적용 보조**. 경제적 판단(목표가·손익비)에 영향 가능.
- 기준선 `c06ea05f`. 사용자 승인: 2026-09-29 ("잘못된 것 고치고 발견한 개선점 같이 배포").
- 변경: (a) 보고서 1-1 프롬프트(KR/US·ko/en): 진행 중 당일 봉의 장중 고가·저가를 주요 저항·지지로 제시하지 않고,
  기존 고점을 넘었으면 그 위 확정 과거 고점(20관측일 이상)을 쓰거나 "확정된 상단 저항 없음"으로 적는다.
  (b) BUY 목표 규칙 2번에 같은 취지 한 줄. (c) `prism_core/breakout_facts.py`: 당일 봉을 제외한 52주(250세션) 확정
  최고가와 2a (a)·(c) 충족 여부를 추세 팩트에 추가. (b)·(d)는 기존처럼 보고서·추세 팩트로 판정.
- 불변: 2a 규칙 자체, 구조적 목표 80% 규칙, R/R floor, 손절·최대 손실, buy_gate, SELL 프롬프트, JSON 스키마.

## 2. 근거와 한계

- 사례: 9/29 KR 오후 HPSP — 보고서가 당일 장중 고가 61,500원을 "단기 저항선"으로 적어 BUY 손익비 0.11.
  같은 날 코세스·삼성전기도 같은 모양.
- 사전등록 재계산 `docs/entry-quality-experiments/confirmed-resistance-target-v1.md`의 판정은 **RETIRE**
  (M1 7.4%, 전환 3건; 계기가 조밀해 M1 하향 편향, 사후 기술 통계 7~40%). 즉 **결정 개선 효과는 입증되지 않았다.**
  이번 변경은 결정론적 저항 대체 규칙을 도입하지 않고, 검증되지 않은 가격을 저항으로 부르지 않게 하는 정확성
  수정과 기존 2a 규칙 적용을 돕는 팩트로 한정한다(재계산에서 2a 적격 DELL·CRWD가 2a를 쓰지 않음, 표본 2건).
- 반대 방향 위험: 당일 고가 대신 더 먼 저항을 쓰면 목표가가 멀어져 진입이 늘 수 있다. R/R floor·손절 한도·
  추세 게이트는 그대로라 위험 한도는 유지된다.

## 3. 궁합

- 스크리닝(마감강도·일중상승 트리거)은 당일 강한 종목을 고르고, 보고서는 그 당일 고가를 저항으로 적어 BUY가
  손익비로 탈락시키던 단계 간 모순을 줄인다. 거래량 하한 판정(#835)과 같은 원칙(미완성 당일 봉을 확정 구조로
  쓰지 않음)이다.
- 신규 팩트 줄은 buy_gate 정규식(T1/T2/분산일/ATR/ADR/regime)과 겹치지 않는다.
