# 모멘텀 신호 1 — 당일 미완성봉 거래량 하한 판정 (KR/US)

## 1. 변경 유형·범위·기준선

- 유형: **오류 수정이면서 경제적 판단에 영향**. BUY 3단계 모멘텀 신호 1
  ("거래량 20일 평균 대비 200% 이상, 당일 또는 최근 3거래일 내")의 '당일' 조건이
  운영 배치에서 한 번도 충족될 수 없던 결함을 복구한다.
- 기준선: `e51e6862` (origin/main). 사용자 승인: 2026-09-29, KR/US 수정 후 배포.
- 변경 계층 하나: BUY 입력의 결정론적 팩트(`_get_trend_facts`) + 그 팩트를 해석하는
  BUY 프롬프트 1줄. 임계값(200%)·창(20세션)·3거래일·트리거 가산·매트릭스·buy_gate·
  주문·손절·SELL 프롬프트는 변경하지 않는다.

## 2. 가설·작동 이유·반증 조건

- 모든 정규 배치는 장중에 실행된다(KR 09:30/14:46 KST, US 10:15/12:30/14:30 ET).
  a843e5d5(9/27)의 "미완성봉은 미확정, 장중 거래량을 정규장 전체와 비교 금지" 지침과
  그 이전부터의 보수적 해석 때문에 BUY는 당일을 항상 제외하고 확정 3세션만 인용했다.
- 거래량은 세션 안에서 누적만 되므로 **미완성봉 거래량은 최종 거래량의 하한**이다.
  장중 값이 이미 200% 이상이면 조건 충족은 확정이다. 200% 미만이면 미확정이며
  "거래량 부진"으로 읽지 않는다. 이 논리는 기존 원칙(미완성봉을 만들어내지 않음)과
  모순되지 않는다 — 추정·외삽(예: 시간 비례 환산)은 하지 않는다.
- 반증 조건: 하한 판정으로 가산된 후보가, 같은 국면·트리거의 기존 후보보다 체결 후
  성과가 체계적으로 나쁘다면(최소 관측 기간 아래 참조) 이 조건 자체의 경제적 가치가
  의심된다. 판정 논리(하한)는 수학적 사실이므로 반증 대상이 아니다.

## 3. 기존 전략과의 궁합 (실제 경로)

| 단계 | 위치 | 확인 결과 |
|---|---|---|
| 스크리닝 | `trigger_batch.py`, `prism-us/us_trigger_batch.py` | 거래량 급증 트리거는 전일 대비 비율. 20일 평균 판정과 별개. 변경 없음 |
| 보고서 | `stock_price_agents`, US `data_prefetch` | 당일 관측 거래량을 "미확정"으로 표기(MDB 15,062,229주). 변경 없음 |
| BUY 입력 | `stock_tracking_agent.py` / `prism-us/us_stock_tracking_agent.py` `_get_trend_facts` | **신규** `prism_core/volume_surge_facts.py` 결과 줄 추가. KR 데이터는 당일 장중 봉 포함(09:13 KST 005930 2,052,124주 확인), US yfinance도 포함 |
| BUY 프롬프트 | 양국 `cores/agents/trading_agents.py` BUY ko/en | 하한 판정 예외 1줄 추가. SELL 프롬프트는 불변(테스트로 보호) |
| 결정론 게이트 | `cores/buy_gate.py` | `momentum_signal_count < min_momentum` floor만 사용. 신규 줄은 T1/T2/ATR/ADR/분산일/regime 정규식과 겹치지 않음 |
| 주문·SELL | 기존 | 변경 없음 |

- 의도한 차이: 트리거 가산(전일 대비 급증)과 신호 1(20일 평균 대비)은 원래 설계
  (#268, 2026-04)부터 별개 항목이다. 당일 급증 종목은 두 항목을 모두 받을 수 있으며,
  이는 확정 3세션 내 급증일 때 이미 허용되던 결과와 같다. 새 중복 가점을 만들지 않는다.
- 하락추세(T1/T2) 종목은 1.5단계 게이트가 우선하므로 신호 개수와 무관하게 미진입이다
  (MDB 반례).
- 미확인: 실제 LLM이 새 팩트로 판단을 바꾸는 정도(동일 후보 LLM 전후 비교)는 실시하지
  않았다.
